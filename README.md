# networkwalks-BO84-week1-lab-setup
Cybersecurity lab setup 

Set up a Kali Linux virtual machine in Oracle VirtualBox as a cybersecurity testing environment. Configured a NAT Network with the 10.0.0.0/24 subnet and assigned Kali a static IP address of 10.0.0.2/24, with full internet access.
Enabled bidirectional clipboard, drag-and-drop, and a shared host Downloads folder mounted at /downloads.
